Etiqueta header

Descripción

La etiqueta <article> se utiliza para definir contenido independiente y autónomo dentro de una página web. Se usa para secciones que pueden existir por sí solas, como: -Noticias -Publicaciones de blog -Artículos -Comentarios -Publicaciones en foros Es una etiqueta semántica de HTML5, lo que significa que ayuda a los navegadores y buscadores a entender la estructura del contenido.

Sintaxis básica

<header> conntenido del encabezado </header>

Atributos comunes

  • id
  • class
  • style
  • title

</header>
