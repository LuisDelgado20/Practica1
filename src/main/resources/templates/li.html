Etiqueta li

Descripción

significa “list item” (elemento de lista) y se utiliza para definir cada elemento dentro de una lista. Siempre se usa dentro de etiquetas de lista como: "ul" → lista desordenada (con viñetas) "ol" → lista ordenada (con números)

Sintaxis básica

    <li>
    <elemento 1>
    <elemento 2>
    </li>

Atributos comunes

  • value
  • type
  • class
  • id

Ejemplo funcional

  • Elemento número uno

    • Código mostrado en pantalla

    <ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
