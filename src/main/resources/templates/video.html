Etiqueta video

Descripción

se utiliza en HTML para insertar y reproducir videos directamente en una página web sin necesidad de usar programas externos.

Sintaxis básica

    <video>
    video reproduciendose
    </video>

Atributos comunes

  • controls
  • autoplay
  • loop
  • muted
  • width
  • height
  • poster

Ejemplo funcional

Código mostrado en pantalla

<video width="400" controls>
  <source src="video.mp4" type="video/mp4">
  Tu navegador no soporta la etiqueta video.
</video>
