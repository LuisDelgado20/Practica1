Etiqueta input

Descripción

La etiqueta <input> se utiliza para crear campos de entrada de datos dentro de un formulario. Permite que el usuario escriba información o seleccione opciones como texto, contraseñas, correos electrónicos, números, fechas, botones, entre otros. Es una etiqueta vacía, lo que significa que no necesita etiqueta de cierre.

Sintaxis básica

<input type="tipo" name="nombre">

Atributos comunes

  • type
  • name
  • value
  • placeholder
  • required
  • maxlength
  • disable
  • readonly
