Etiqueta dl

Descripción

significa Definition List (lista de definiciones). Se utiliza para crear listas de términos y sus definiciones. Esta etiqueta funciona junto con: "dt" → término o concepto. "dd" → definición o descripción del término.

Sintaxis básica

    <dl>
    <dt>elemento 1</dt>
    <dt>elemento 2</dt>
    </dl>

Atributos comunes

  • id
  • class
  • style
  • title

Ejemplo funcional

HTML
CSS
Lenguaje usado para dar estilo y diseño a las páginas web.
JavaScript
Lenguaje de programación que permite agregar interactividad a las páginas web.

Código mostrado en pantalla

<dl>
  <dt>HTML</dt>
  <dd>Lenguaje para crear páginas web</dd>

  <dt>CSS</dt>
  <dd>Lenguaje para dar estilo a las páginas</dd>
</dl>
