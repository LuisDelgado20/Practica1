Etiqueta Body

Descripción

se utiliza para contener todo el contenido visible de una página web. Dentro de esta etiqueta se colocan elementos como textos, imágenes, enlaces, tablas, listas, formularios, videos, etc.

Sintaxis básica

    <body>
    contenido
    </body>

Atributos comunes

  • bgcolor
  • text

Ejemplo funcional

Esta página está dentro de una etiqueta Body.
