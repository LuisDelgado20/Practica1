Etiqueta tbody

Descripción

se utiliza para agrupar el contenido del cuerpo de una tabla en HTML. Sirve para organizar las filas principales de datos dentro de una tabla, separándolas de otras partes como: <thead> → encabezado de la tabla <tbody> → cuerpo o datos de la tabla <tfoot> → pie de la tabla

Sintaxis básica

   <table>
    <tbody >
        <th>encabezado 1</th>
        <td>texto</td>
    <tbody>
</table>

Atributos comunes

  • align
  • valign
  • class
  • id
  • style

Ejemplo funcional

Ana 20

Código mostrado en pantalla

<tbody>
  <tr>
    <td>Ana</td>
    <td>20</td>
  </tr>

  <tr>
    <td>Carlos</td>
    <td>22</td>
  </tr>
</tbody>
