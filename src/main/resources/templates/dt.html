Etiqueta dt

Descripción

significa Definition Term (término de definición). Se utiliza para definir el término o nombre dentro de una lista de definiciones. Siempre se usa dentro de la etiqueta "dl" (lista de definiciones) y normalmente va acompañada de "dd", que contiene la descripción del término.

Sintaxis básica

    <dl>
    <dt>elemento 1</dt>
    <dt>elemento 2</dt>
    </dl>

Atributos comunes

  • id
  • class
  • style
  • title

Ejemplo funcional

HTML
Lenguaje de marcado para crear páginas web.
CSS
Lenguaje usado para dar estilo a las páginas web.
JavaScript
Lenguaje de programación que agrega interactividad.

Código mostrado en pantalla

<dl>
  <dt>HTML</dt>
  <dd>Lenguaje de marcado para crear páginas web</dd>
</dl>
