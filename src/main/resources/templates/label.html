Etiqueta label

Descripción

La etiqueta <label> se utiliza para asociar un texto descriptivo con un campo de formulario (como input, textarea, select). Sirve para que el usuario sepa qué información debe escribir en cada campo. Además, mejora la accesibilidad, porque al hacer clic en el texto del label también se activa el campo correspondiente.

Sintaxis básica

<label for="id_del_input">Texto del campo> <input type="text" id="id_del_input">

Atributos comunes

  • for
  • id
  • class
  • style
  • title

Ejemplo funcional





Código mostrado en pantalla

<label for="nombre">Nombre:</label>
<input type="text" id="nombre">
