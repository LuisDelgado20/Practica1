Etiqueta form

Descripción

La etiqueta <form> se utiliza en HTML para crear formularios que permiten a los usuarios ingresar y enviar datos a un servidor. Los formularios se usan para registros, inicios de sesión, encuestas, búsquedas y envío de información.

Sintaxis básica

    <form>
     campos del formulario
    </form>

Atributos comunes

  • action
  • method
  • name
  • target
  • autocomplete
  • enctype

Ejemplo funcional

Código mostrado en pantalla

<form >

<label>Nombre:</label>
<input type="text" name="nombre">

<label>Correo:</label>
<input type="email" name="correo">

<input type="submit" value="Enviar">

</form>
