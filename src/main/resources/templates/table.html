Etiqueta table

Descripción

se utiliza en HTML para crear tablas que permiten organizar información en filas y columnas. Se usa comúnmente para mostrar datos estructurados, como horarios, listas de productos, calificaciones, etc.

Sintaxis básica

  <table>
<th>encabezado 1</th>
<td>texto</td>
</table>

Atributos comunes

  • border
  • width
  • cellpadding
  • cellspacing
  • aling

Ejemplo funcional

Nombre Edad Carrera

Código mostrado en pantalla

<table border="1">
  <tr>
    <th>Nombre</th>
    <th>Edad</th>
  </tr>

  <tr>
    <td>Luis</td>
    <td>20</td>
  </tr>
</table>
