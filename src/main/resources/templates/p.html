Etiqueta P

Descripción

se utiliza para definir un párrafo de texto en una página web. Sirve para organizar el contenido en bloques de texto, haciendo que el navegador agregue automáticamente un espacio antes y después del párrafo para mejorar la lectura.

Sintaxis básica

    <p>
    Parrafo de texto
    </p>

Atributos comunes

  • id
  • class
  • style

Ejemplo funcional

Este es el primer párrafo de mi página.

Código mostrado en pantalla

<p>Este es un párrafo de texto.</p>
