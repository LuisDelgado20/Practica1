Etiqueta td

Descripción

(table data) se utiliza para definir una celda de datos dentro de una tabla en HTML. Se coloca dentro de una fila de tabla <td> y sirve para mostrar información dentro de las columnas de la tabla. Cada <td> representa una celda donde se pueden colocar textos, imágenes, enlaces u otros elementos HTML.

Sintaxis básica

    <table>
<th>
<td>texto</td>
</th>
</table>

Atributos comunes

  • class
  • id
  • style
  • colspan
  • rowspan
  • headers

Ejemplo funcional

Juan 20 México

Código mostrado en pantalla

<table border="1">
<tr>
<td>Juan</td>
<td>20</td>
<td>México</td>
</tr>
</table>
