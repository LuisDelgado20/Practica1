Etiqueta tr

Descripción

(table row) se utiliza en HTML para crear una fila dentro de una tabla. Se coloca dentro de la etiqueta "table" y normalmente contiene celdas definidas con "td" (datos) o "th" (encabezados).

Sintaxis básica

<tr> <dato 1> <dato 2> </tr>

Atributos comunes

  • align
  • valign
  • bgcolor
  • class
  • id
  • style

Ejemplo funcional

Nombre Edad Carrera

Código mostrado en pantalla

<tr>
  <td>Luis</td>
  <td>20</td>
  <td>Ingeniería</td>
</tr>
