Etiqueta img

Descripción

se utiliza en HTML para insertar imágenes en una página web. Permite mostrar imágenes como fotos, ilustraciones, íconos o gráficos que están guardados en el mismo proyecto o en internet.

Sintaxis básica

    <img>
    imagen
    </img>

Atributos comunes

  • src
  • alt
  • width
  • height
  • title

Ejemplo funcional

Código mostrado en pantalla

<img src="imagen.jpg" alt="Imagen de ejemplo" width="300">
