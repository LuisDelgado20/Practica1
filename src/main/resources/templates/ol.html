Etiqueta ol

Descripción

significa Ordered List (lista ordenada). Se utiliza para crear listas donde los elementos tienen un orden específico, normalmente numerados.

Sintaxis básica

    <ol>
    <elemento 1>
    <elemento 2>
    </ol>

Atributos comunes

  • type
  • start
  • reversed

Ejemplo funcional

  1. HTML
  2. CSS
  3. JavaScript

Código mostrado en pantalla

<ol>
  <li>Hervir agua</li>
  <li>Agregar café</li>
  <li>Servir en una taza</li>
</ol>
